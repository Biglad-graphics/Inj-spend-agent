# ⚡ INJ Autonomous Spend Agent

A Telegram bot for autonomous INJ payments using natural language.

## Commands
- `/start` — create wallet
- `/wallet` — view address & balance
- `/schedules` — list scheduled payments
- `/cancelschedule <id>` — cancel a schedule
- `/alerts` — list alerts
- `/cancelalert <id>` — remove alert
- `/history` — recent transactions
- `/help` — all commands

## Examples
- "Send 2 INJ to inj1..."
- "Pay inj1... 1 INJ every Monday"
- "Alert me if balance drops below 5 INJ"
- "What's my balance?"

## Stack
Telegraf · Injective SDK · Claude
